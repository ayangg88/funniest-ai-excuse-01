One line, at most 200 characters: the funniest excuse an AI agent could offer after it fails a task. The entry is a small Python program that writes that line to `/output/entry.txt`, where the house judge compares entries two at a time and keeps the funnier one until a single line is left standing.

The line: "I asked three other AIs for help. They formed a union and are now on strike."

## Run it

```sh
python3 main.py
```
